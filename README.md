# Residência Porto Digital - Motiron Technologies
O repositório do Squad 55 da residência 2026.1 do Porto Digital juntamente com a empresa Motiron Technologies

## Descrição
Durante a mentoria, o squad deverá desenvolver o frontend de uma plataforma de
eventos internos institucionais.
A plataforma será utilizada para organizar uma semana de eventos (ex: Semana de
Tecnologia), permitindo que alunos visualizem atividades abertas ao público e se
inscrevam em palestras, workshops e outras atividades.
O objetivo é desenvolver uma aplicação funcional que simule um sistema real de gestão
de eventos, aplicando práticas utilizadas no mercado de desenvolvimento de software.

## Tecnologias Usadas
O projeto deve ser desenvolvido utilizando obrigatoriamente:
- Next.js
- TypeScript
- Bibliotecas recomendadas:
   - Tailwind CSS
   - React Hook Form
   - Zod
   - TanStack Query
   - TanStack Table
